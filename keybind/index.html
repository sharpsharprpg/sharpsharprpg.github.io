상황

키보드

키를 누르면 그 키에 묶인 기능이 아래에 나옵니다. 오른쪽 위 숫자 = 기능 수, 왼쪽 아래 점 = Shift·Ctrl·Alt 조합이 있는 키. 같은 키의 여러 기능은 상황(총을 들었을 때, 탈것에 탔을 때, 창이 열렸을 때 등)에 따라 그중 하나가 동작합니다.

마우스

버튼을 누르면 아래 「고른 키」에 자세히 나옵니다. 마우스 4·5 는 옆면의 뒤로·앞으로 버튼입니다. 색과 목록은 위에서 고른 상황을 따릅니다.

전체 목록

게임 안에서는 K 키(Keybind Atlas)로 같은 배치도를, 옵션 → 조작에서 키를 바꿀 수 있습니다. 「번역 없음」 표시가 붙은 기능은 게임 조작 화면에 내부 이름이 그대로 보이며, 여기 이름은 위키에서 붙인 것입니다.
